# 健康管家

一个单文件网页健康追踪应用（PWA），支持双人使用、体重/BMI 记录、饮食营养记录、AI 食物识别、运动消耗记录、菜谱推荐、记账与票据识别、趋势图表和家庭共享云同步。

## 使用方式

1. 本地打开 `index.html` 即可体验核心记录与图表功能（部分依赖服务端的能力不可用）。
2. 完整部署（推荐）：将本目录部署到 Cloudflare Pages。`functions/api/` 提供食物搜索、拍照识别、运动搜索、菜谱、健康教练等服务端接口，纯静态托管（如 GitHub Pages）无法运行这些接口，相关功能会自动降级。
3. 多设备同步：在设置中填写相同的家庭共享码，数据通过内置配置的云数据库同步。

## 目录结构

- `index.html`：应用主体（核心逻辑）
- `js/`：功能模块（云同步、AI、双人空间、菜谱、Health Connect 对接等）
- `functions/api/`：Cloudflare Pages Functions 服务端接口
- `css/`、`assets/`：样式与图标资源
- `tests/`、`interaction-map/`：回归测试脚本与交互说明图
- `service-worker.js`、`manifest.json`：PWA 离线缓存与安装配置

## 说明

- 当前版本已清除测试记录与调试/临时文件。
- 云同步支持新增和删除记录：体重、饮食、运动记录删除后会写入删除标记，其他设备同步时不会再被旧云端数据恢复。
- 体重、饮食、运动记录时间均使用下拉选择器选择年月日时分。
- 本项目是纯静态网页，无需构建步骤。
- Android 壳工程（`android/` 目录）与打包好的 APK 均不包含在本仓库中，仅保留在本机；如需重新打包 APK，请使用本机保留的壳工程。
- 如仓库会公开，请注意：当前版本内置了云同步（Supabase）配置与 AI 服务端接口，公开前建议确认云数据库已开启行级安全策略（RLS），并为服务端接口增加访问限制。
