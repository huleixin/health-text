# 健康管家

一个单文件网页健康追踪应用，支持双人使用、体重/BMI记录、饮食营养记录、AI食物识别、运动消耗记录、趋势图表和家庭共享云同步。

## 使用方式

1. 直接打开 index.html 使用。
2. 如果部署到 GitHub Pages，把本目录提交到仓库后启用 Pages 即可。
3. 多设备同步时，在设置中填写相同的家庭共享码。

## 说明

- 当前导出的版本已清除测试记录，默认不会读取旧版本地测试数据。
- 云同步支持新增和删除记录：体重、饮食、运动记录删除后会写入删除标记，其他设备同步时不会再被旧云端数据恢复。
- 体重、饮食、运动记录时间均使用下拉选择器选择年月日时分。
- 本项目是纯静态网页，无需构建步骤。
- 如仓库会公开，请注意：当前版本按需求内置了云同步与 AI 识别配置，公开前建议确认这些配置是否允许暴露。
